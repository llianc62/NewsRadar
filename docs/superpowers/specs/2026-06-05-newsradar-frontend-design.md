# NewsRadar 前端设计规范

## 概述

NewsRadar 是一个金融分析新闻 Web 服务，前端采用 **FastAPI + Jinja2 SSR** 架构。设计风格为现代 Fintech Dashboard，浅色系 + 橙色点缀，左侧导航栏 + 右侧内容区。

## 技术栈

- **后端框架**：FastAPI
- **模板引擎**：Jinja2（SSR）
- **图标库**：Lucide Icons（SVG inline）
- **字体**：Inter（正文/UI）+ JetBrains Mono（数据/数字，`tabular-nums`）
- **数据库**：SQLite（现有）

## 布局结构

```
┌──────────┬──────────────────────────────┐
│ Sidebar  │  内容区                       │
│ 220px    │  flex:1                      │
│          │                              │
│ Logo     │  无顶部状态栏                 │
│ Nav × 7  │  页面标题不重复出现在内容区    │
│          │                              │
└──────────┴──────────────────────────────┘
```

- **无首页**：进入即展示市场概览
- **无用户模块**：扁平结构
- **无顶部状态栏**：内容区最大化

## 设计系统

### 色彩（HSL）

| Token | 值 | 用途 |
|-------|-----|------|
| `--background` | `220 20% 98%` | 页面背景 |
| `--foreground` | `220 20% 10%` | 主文字 |
| `--card` | `0 0% 100%` | 卡片背景 |
| `--primary` | `27 90% 52%` | 主色调（橙色） |
| `--muted` | `220 14% 92%` | 次级背景 |
| `--muted-foreground` | `220 14% 46%` | 次级文字 |
| `--border` | `220 14% 87%` | 边框 |
| `--radius` | `0.5rem` / `6px–14px` | 圆角 |

### 语义色

| Token | HSL | 含义 |
|-------|-----|------|
| `--success` | `142 71% 45%` | 利空（中国习惯：绿跌） |
| `--danger` | `0 84% 60%` | 利好（中国习惯：红涨） |
| `--warning` | `38 92% 50%` | 中性 |
| `--info` | `217 91% 60%` | 信息 |

### 中国股市颜色惯例

- **利好 = 红色**（`hsl(0,84%,60%)`）：涨/正面
- **利空 = 绿色**（`hsl(142,71%,45%)`）：跌/负面
- **中性 = 黄色**（`hsl(38,92%,50%)`）

### 字体

- **正文/UI**：`'Inter', system-ui, -apple-system, sans-serif`，13px 导航，12-13px 正文
- **数据/数字**：`'JetBrains Mono', monospace`，`font-feature-settings: 'tnum'`，19-24px 大数字

### Tier 级别标签

来自 `notifier.py:18` 的 `TIER_LABELS`：

| Tier | Label | 颜色 | 背景 |
|------|-------|------|------|
| 1 | 官媒 | `#059669` | `#ecfdf5` |
| 2 | 主流 | `#2563eb` | `#eff6ff` |
| 3 | 垂直 | `#d97706` | `#fffbeb` |
| 4 | 资讯 | `#6b7280` | `#f3f4f6` |

列表中仅显示中文 Label（官媒/主流/垂直/资讯），过滤栏显示完整形式（T1·官媒 等）。

- 宽度：220px，白色背景，右侧边框 `hsl(220,14%,87%)`

## 页面二：热点新闻

### 页面结构

```
┌──────────────────────────────────────────────┐
│ 筛选：                                       │
│ 级别  [全部] [T1·官媒] [T2·主流] [T3·垂直] [T4·资讯] │
│ 标签  [全部] [利好] [利空] [央行] [AI] [港股] [外资] [芯片] [新能源] │
├──────────────────────────────────────────────┤
│ 📊 86 今日热点 │ 7 新闻来源 │ 8 热点新闻 │ 62% 利好指数 │
├────────────────────────┬─────────────────────┤
│ 竖式卡片瀑布流（flex:2） │ 其他新闻列表（flex:1）│
│ CSS columns:2          │ 无表头，无内滚动     │
│ 仅 T1·官媒，≤10 张      │ # 标题    来源      │
│                        │ 带分页器 10条/页    │
└────────────────────────┴─────────────────────┘
```

### 全局过滤栏

- **两级过滤**：
  - 第一级"级别"：按 Tier 级别过滤（T1·官媒 / T2·主流 / T3·垂直 / T4·资讯）
  - 第二级"标签"：按情感（利好/利空）+ 主题关键词过滤
- 全部标签为橙色高亮（激活态），其余为对应语义色或灰色
- 两级联动：先粗筛后精筛，同时影响瀑布卡片区和右侧列表

### 统计栏

4 张统计卡片，每张包含图标 + 标签 + 大数字：
- **今日热点**：橙色图标，统计总数
- **新闻来源**：蓝色图标，来源数量
- **热点新闻**：黄色图标，T1 级别数量
- **利好指数**：红色图标，利好占比百分比

### 左侧瀑布卡片区

- **布局**：CSS `column-count: 2; column-gap: 14px`
- **范围**：仅 Tier 1（官媒），最多 10 张
- **溢出处理**：超过 10 条的 T1 新闻进入右侧列表头部
- **滚动**：无内部滚动条，整页滚动

#### 卡片设计

- 白色背景，圆角 14px，1px 边框 `hsl(220,14%,87%)`
- **无红绿左边框**
- 内边距 24px，纵向 flex 布局，gap 16px
- 卡片内部结构（自上而下）：

```
[利好徽标]  [来源 · 时间]         [🔥 热力值]
标题（15-16px, 700）
──────────────────（分割线）
摘要（13px, line-height 1.8）
· 分析要点（可选）
[关键词1] [关键词2] [关键词3]
```

- 利好/利空/中性徽标位于卡片顶部左侧，无左边框
- 关键词：11px，padding 5px 12px，圆角 14px
  - 主关键词：`hsl(27,90%,52%,0.08)` 背景 + `hsl(27,90%,52%)` 颜色
  - 次级关键词：`hsl(220,14%,92%)` 背景 + `hsl(220,14%,46%)` 颜色
- 卡片高度不一（内容量不同），CSS columns 自然流动形成瀑布效果

### 右侧新闻列表

- **无 "#, 标题, Tier" 表头**
- **无内部滚动条**，随页面整体滚动
- 列表项：padding 9px 16px，flex 行布局
- 三列结构：

```
 #  标题                          来源
 1  北向资金今日净买入超120亿...    华尔街见闻
 2  恒生科技指数涨超3%...          财联社
 3  比特币重返6.5万美元...         今日头条
...
```

- **序号**：JetBrains Mono，28px 固定宽度，从 1 开始连续编号
- **标题**：flex:1，12px/500
- **来源**：10px，右对齐，52px 最小宽度，灰色文字

#### 分页

- 底部固定栏：左侧 "第 1-10 条"，右侧翻页按钮
- 每页 10 条
- 页码按钮：‹ 1 2 3 … 8 ›
- 当前页：橙色背景白色文字，其余白色背景边框

### 数据流

```
新闻数据（news_items 表）
  │
  ├─ Tier 1（官媒）
  │   ├─ ≤10 条 → 左侧瀑布卡片
  │   └─ >10 条溢出 → 右侧列表头部
  │
  └─ Tier 2-4（主流/垂直/资讯）
      └─ 右侧分页列表，按热度排序
```

### 标签过滤逻辑

1. 用户选择 Tier 级别（如 T2）→ 页面仅显示 T2·主流 新闻
2. 用户再选标签（如 利好）→ 在 T2 范围内过滤利好新闻
3. 选"全部" → 清除该级过滤
4. 两级独立但联动，级联缩小范围
